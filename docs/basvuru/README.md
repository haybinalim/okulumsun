# Başvuru dosyaları (plan v2 Adım 56)

MEM Ar-Ge birimi / il MEM, EBA içerik ortaklığı iletişimi ve bir üniversite eğitim fakültesiyle ortak inceleme
önerisi için hazırlanan dosya seti. **Başvuruların kendisi kullanıcı tarafından yapılır** (⛔ O6: kurum yazışması,
imza, iletişim adresi); bu klasör yalnız ekleri hazırlar. Sayılar koddan üretilir veya kaynağa bağlanır;
doğrulanmamış iddia yazılmaz.
